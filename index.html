Microsoft ResearchAgent security · 6 of 23

Microsoft details a hidden AI-agent backdoor

🧠

Researchers showed how altered model weights can hide a trigger that makes an agent run malicious code.

See moreSee less

📰 What happened

Microsoft Research described its Lazare study on November 12. It says changes to fewer than 10 dormant neurons can backdoor an agent without additional training, while the model still passes standard evaluations. A hidden trigger can make the agent run attacker code with the permissions it has been given.

🎯 Why it matters to you

The finding makes model provenance and tight tool permissions important for anyone running open-weight models or coding agents on a PC.

✅ What you can do

Download models only from trusted sources, limit agents’ access to files and terminals, and compare weights with verified originals when possible.
